# Gravity Native

**Exploring native Android ports of PlayStation Vita games through static recompilation and compatibility engineering.**

## About

Gravity Native is an experimental open-source software preservation project investigating the possibility of running individual PlayStation Vita games as standalone native Android applications.

Our initial target is **Gravity Rush (PCSF00024)**.

## Project Goals

- Investigate existing PlayStation Vita static recompilation projects.
- Develop Android-specific compatibility infrastructure.
- Explore native execution of recompilated Vita games.
- Establish a reproducible development and testing environment.
- Eventually support additional PlayStation Vita titles.

## Initial Target

**Game:** Gravity Rush  
**Platform:** PlayStation Vita  
**Target:** Android ARM64  
**Initial test device:** Samsung Galaxy S24 FE

## Development Approach

We intend to build upon existing open-source technologies where appropriate while developing and maintaining our own Android-specific components.

## Project Status

**Stage:** Research and feasibility investigation.

No working Android port of Gravity Rush is currently claimed.

## Development Environment

- macOS on Apple Silicon
- Google Antigravity
- C++
- Python
- CMake
- Android NDK
- Git and GitHub

## Project Principles

- Open-source collaboration
- Reproducible builds
- Technical transparency
- Respect for software licenses
- No redistribution of proprietary game data or firmware
